# Contributing to M175a Studio

## Process
1. Review the [Project Specification](PROJECT_SPECIFICATION.md) and [Roadmap](ROADMAP.md) to understand the current phase and goal.
2. Follow the [Coding Guidelines](CODING_GUIDELINES.md).
3. Ensure any changes to hardware interaction are documented in [Scanner Protocol](SCANNER_PROTOCOL.md) or [Printer Protocol](PRINTER_PROTOCOL.md).

## Strict Scope
This repository is dedicated **exclusively** to the HP LaserJet 100 color MFP M175a. 
- Do **not** submit PRs for generic receipt printers.
- Do **not** submit PRs for barcode printers.
- Do **not** submit ESC/POS or ZPL integrations.
- Do **not** rename the project from M175a Studio.
- Do **not** change the application name.

By contributing, you agree to adhere strictly to the established protocols and project bounds.
